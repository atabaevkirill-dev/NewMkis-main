# MKIS100TEST

Переносимый desktop-клиент проекта на Tauri 2, Rust, React и TypeScript. Внутренние идентификаторы (`ru.oncam.cockpit`, крейт `oncam-desktop`) сохранены, чтобы не потерять уже сохранённые настройки и пароли. Старое PyQt-приложение сохранено в корне репозитория как источник аппаратной логики на время поэтапной миграции.

## Клонирование на другую машину

Установите:

- Git;
- Node.js 22 LTS (не ниже 22.12);
- Rust stable через `rustup`;
- системные зависимости Tauri для вашей ОС (на Linux дополнительно `libdbus-1-dev` для связки ключей Secret Service).

Затем выполните:

```bash
git clone https://github.com/atabaevkirill-dev/NewMkis-main.git
cd NewMkis-main/desktop
npm ci
npm run doctor
npm run check
npm run dev:native
```

`npm ci` использует зафиксированный `package-lock.json`, а Cargo — `Cargo.lock`. Каталоги `node_modules`, `dist`, `target` и локальные конфигурации в Git не сохраняются.

### Только интерфейс в браузере

```bash
npm run dev
```

После запуска откройте `http://127.0.0.1:1420`. Не открывайте `desktop/index.html` через `file://`: это исходный файл Vite, а не автономная сборка.

## Проверки

```bash
npm run doctor  # версии Node, npm, Rust и Cargo
npm run check   # TypeScript/Vite + cargo check
cargo test --manifest-path src-tauri/Cargo.toml  # драйвер TL.0009 против эмулятора, конфиг, валидация
npm run build   # production-сборка интерфейса
npm run tauri build  # установщики для текущей ОС: src-tauri/target/release/bundle
```

Готовые установщики для Windows (`.exe`, `.msi`), macOS (`.dmg`) и Linux собирает GitHub Actions ([workflow](../.github/workflows/desktop.yml)); на теге `v*` они публикуются в Releases.

## Что уже перенесено

- компактный каркас: одна верхняя строка, видео на всю площадь, строка статуса;
- единая изменяемая поверхность CAM 01 и CAM 02: разделитель перетаскивается, двойной клик — поровну, кнопка на разделителе меняет камеры местами;
- боковые и верхняя push-панели, не перекрывающие видео;
- до трёх перекрестий на камеру: вид (9 вариантов), цвет, длина горизонтали и вертикали, толщина, разрыв, радиус, непрозрачность, смещение, тёмная обводка; переключатель «Применять к обоим окнам»;
- модули устройств в «Сводке»: добавление, переименование (в том числе встроенных), изменение адреса, скрытие, удаление с подтверждением; статус связи опрашивается каждые 5 с;
- полное наименование изделия рядом с названием приложения (клик — изменить);
- PDF-протокол проверки работоспособности на вкладке «Тесты»: строится только из выполненных проверок, с заключением «исправно / неисправности / не завершено», заводским номером и оператором (печать → «Сохранить как PDF»);
- нижняя строка общей телеметрии без дублирования в видео (нет данных — показывается «—»);
- опциональный компактный OSD камеры и D-pad только при наведении на видео;
- колесо над видео — ONVIF zoom, правая кнопка + колесо — ONVIF focus (команды пока отвечают «адаптер не подключён»);
- хранение паролей в системной связке ключей; показ пароля — только по кнопке и на 10 секунд;
- сервисные команды TL.0009: движение только пока кнопка удерживается, сторожевой таймер, глобальный СТОП (кнопка и Esc), пять профилей качки с индикацией циклов;
- TCP-проверки модулей и настройки раздельной/совместной записи;
- атомарное сохранение конфигурации и восстановление после повреждения файла.

## Аппаратный профиль

| Устройство | Адрес | Протокол |
|---|---:|---|
| CAM 01 | `192.168.1.68` | ONVIF / RTSP |
| CAM 02 | `192.168.1.108` | ONVIF / RTSP |
| TL.0009 | `192.168.1.115:9762` | сервисный протокол `$...#` |
| Дальномер | `192.168.1.7:20108` | TCP |
| Relay X3 | `192.168.127.254:9762` | TCP / Pelco-D legacy |

Порт TL.0009 изменяемый. В заводском руководстве порт управления показан как `9760`, Pelco-D — `9761`, RS-485 — `9762`; рабочий профиль этого проекта по указанию владельца использует `9762`. Новое управление повороткой не отправляет Pelco-D и работает только командами сервисного протокола.

## Безопасность конфигурации

- IP-адреса, порты и пользовательские настройки сохраняются в каталоге приложения, который предоставляет ОС.
- Пароли камер не попадают в JSON и Git; Tauri хранит их через системный keychain.
- Пароль можно временно показать в интерфейсе и скрыть обратно.
- Запись паролей в metadata запрещена по умолчанию; предусмотрен только отдельный зашифрованный manifest с явным включением.

## Граница текущего среза

Интерфейс, конфигурация, keychain, сетевое обнаружение и TCP-драйвер сервисных команд TL.0009 уже собраны. Реальное декодирование RTSP, полноценный ONVIF-адаптер zoom/focus и запись FFmpeg ещё должны быть соединены с новым клиентом. До этого видеообласти показывают состояние ожидания подключения, а browser-preview не отправляет аппаратные команды.
