# Дальномер: протокол обмена и работа в приложении

Лазерный дальномер 3 км, 1535 нм, класс 1 (безопасен для глаз). Источник — руководство «3Km Eye-Safe Laser Ranging Module User Manual» V1.2 (2022.12); сведения проверены на модуле стенда (2026-10-02).

## Подключение

- Модуль: UART TTL 3,3 В, 115200 (также 57600, 9600), 8N1, старшим битом вперёд. После включения ему нужно около 0,5 с.
- На стенде модуль стоит за преобразователем «последовательный порт ↔ TCP»: `192.168.1.7:20108`. Логин и пароль преобразователя нужны только его веб-странице; канал данных их не спрашивает. Преобразователь принимает несколько TCP-клиентов одновременно.
- Ответы на запросы приходят за 3–10 мс; первый замер после включения — до 600 мс.

## Кадр

| Поле | Размер | Значение |
|---|---|---|
| Заголовок | 2 | `EE 16` |
| Длина | 1 | число байт «код устройства + код команды + параметры» (2–6) |
| Код устройства | 1 | `03` |
| Код команды | 1 | см. таблицу |
| Параметры | 0–4 | |
| Контрольная сумма | 1 | младший байт суммы «код устройства + код команды + параметры» |

Ответы модуля — кадры того же вида. Пример: одиночный замер `EE 16 02 03 02 05`, ответ «вне диапазона» `EE 16 06 03 02 04 00 00 00 09`.

## Команды

| Код | Назначение | Параметры запроса | Ответ |
|---|---|---|---|
| `01` | Самодиагностика (импульс лазера) | — | 4 байта, см. ниже |
| `02` | Одиночный замер (импульс) | — | 4 байта замера |
| `03` | Режим цели | `01` первая, `02` последняя, `03` несколько | без параметров |
| `04` | Непрерывный замер | — | кадры `04` с замерами, пока не остановлен |
| `05` | Стоп непрерывного замера | — | `EE 16 02 03 05 08` |
| `06` | (только ответ) отчёт о сбое после замера | — | `резерв×3, status1` |
| `A1` | Частота непрерывного замера | `частота 1–10 Гц, 00` | без параметров |
| `A2` / `A3` | Задать / запросить ближнюю границу строба | `старший, младший` байт метров (10–20000) | 2 байта |
| `A4` / `A5` | Задать / запросить дальнюю границу строба | то же | 2 байта |
| `A6` / `A7` | Версия FPGA / MCU | — | `версия, день, месяц·год, автор` |
| `A8` | Версии плат | — | `основная, управление, приёмник, драйвер` |
| `A9` | Серийный номер | — | `месяц·год, номер_старший, номер_младший` |
| `90` / `91` | Импульсов всего / с включения | — | 3 байта, старшим вперёд |

Версия: старший полубайт — major, младший — minor (`0x16` = V1.6). Месяц·год: старший полубайт — месяц, младший — год от 2020.

## Ответы

**Замер (`02`, `04`)** — 4 байта: `статус, дальность_старший, дальность_младший, десятые`. Дальность, м = `старший × 256 + младший + десятые × 0,1`.

Статус: младший полубайт — `0` одна цель, `1` есть цель ближе, `2` есть цель дальше, `3` есть ближе и дальше, `4` вне диапазона (нет цели в стробе). Старший полубайт в режиме нескольких целей — номер цели (0…N−1): на один замер приходит по кадру на каждую цель подряд.

**Самодиагностика (`01`)** — `s3 s2 s1 s0`: `s2` — интенсивность эха; `s1` (1 — норма) биты: 0 FPGA, 1 излучение лазера, 2 опорный импульс, 3 эхо (0 — просто нет цели), 4 ключ смещения, 5 смещение приёмника, 6 температура, 7 излучение не заблокировано; `s0` бит 0 — питание 5,6 В. Пример исправного модуля без цели: `FF 00 F7 FF`.

**Сбой (`06`)** приходит после ответа на замер, только если в `status1` есть ненормальный бит.

## Модуль стенда

Зав. № 06.2025 № 86 · FPGA V1.6 (28.02.2024) · MCU V2.3 (20.12.2023) · платы V2.3 / V2.3 / V1.3 / V1.3 · строб 15–4200 м · 9475 импульсов на 2026-10-02.

## Как работает в приложении

- **Связь.** Одно постоянное соединение (`src-tauri/src/rangefinder.rs`): открывается при запуске (приложение сразу задаёт модулю выбранный режим цели) и восстанавливается при следующей команде. Каждый замер приходит в окно событием и показывается у прицела, в строке состояния (RANGE) и на вкладке «Дальномер».
- **Замер.** Кнопка «Замер» или клавиша R (физическая клавиша, при любой раскладке; не срабатывает, пока курсор в поле ввода). По умолчанию дальномер сам делает замер, когда оператор отпускает кнопку D-pad и поворотка постояла 0,7 с.
- **Непрерывный замер** 1–10 Гц всегда ограничен сроком (по умолчанию 60 с): его останавливает сторожевой поток, кнопка «Стоп», общий СТОП / Esc и выход из программы. Неподтверждённый стоп повторяется раз в секунду.
- **На перекрестии** — как в дальномерном прицеле: крупные цифры под первым включённым прицелом, его цветом с тёмной обводкой; над перекрестием — режим цели и «● N Гц» в непрерывном режиме; в режиме нескольких целей остальные дальности столбиком под основной; «- - - -» и «нет цели в стробе», если в стробе пусто; пока идёт замер — мигающие «– – – –» и пульсирующее кольцо. Одиночный замер старше 5 с тускнеет. Где показывать: обе камеры, одна или нигде. В сплит-записи — так же, вместе с прицелами.
- **Прицел дальномера** — кнопка «Дальномер» в верхней панели: вместо перекрестий на окнах, где показывается дальность, рисуется прицел с встроенной дальностью. Виды: тактический (mil-dot), шеврон (как ACOG), рамка (как в лазерных дальномерах, мигает при замере), коллиматор (голографический, светится). Цвет, размер, яркость и точка прицеливания луча для каждой камеры (смещение от центра: луч дальномера выставляется относительно камеры) — на вкладке «Дальномер». На время «Сведения» возвращаются обычные перекрестия.
- **Строб** хранится в самом модуле: вкладка читает его и записывает кнопкой.
- **Самодиагностика** — на вкладке и в «Тестах»; результат идёт в протокол испытаний.

Проверка без излучения: `real_rangefinder_info` (см. `CLAUDE.md`).
