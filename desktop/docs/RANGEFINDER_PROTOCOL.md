# Дальномер: протокол обмена

Лазерный дальномер 3 км, 1535 нм, класс I. Сведения перенесены из прежнего Python-клиента (`rlf/protocol_handler.py`, удалён в v0.2.0; код доступен в истории git по тегу `v0.1.0`). Новый клиент пока проверяет только TCP-связь с дальномером; команды ниже ещё не реализованы.

## Подключение

- TCP: `192.168.1.7:20108` (по умолчанию проекта).
- UART TTL 3,3 В: 115200 (также 57600, 9600), 8N1, старшим битом вперёд.
- После включения модулю нужно около 0,5 с на инициализацию.

## Кадр

| Поле | Размер | Значение |
|---|---|---|
| Заголовок | 2 | `EE 16` |
| Длина | 1 | число байт «код устройства + код команды + параметры» (2–6) |
| Код устройства | 1 | `03` |
| Код команды | 1 | см. таблицу |
| Параметры | 0–4 | |
| Контрольная сумма | 1 | младший байт суммы «код устройства + код команды + параметры» |

Пример: одиночное измерение — `EE 16 02 03 02 05`.

## Команды

| Код | Назначение | Параметры запроса |
|---|---|---|
| `01` | Самодиагностика | — |
| `02` | Одиночное измерение | — |
| `03` | Режим цели | `01` первая, `02` последняя, `03` несколько |
| `04` | Непрерывное измерение | — |
| `05` | Стоп измерений | — |
| `06` | Сообщение об ошибке измерения | — |
| `07` | Выход из режима пониженного потребления | — |
| `A0` | Скорость UART | |
| `A1` | Частота измерений | `частота (1–10 Гц), 00` |
| `A2` / `A3` | Задать / запросить минимальную дальность стробирования | `старший, младший` байт метров |
| `A4` / `A5` | Задать / запросить максимальную дальность стробирования | `старший, младший` байт метров |
| `A6` / `A7` / `A8` | Версия FPGA / MCU / аппаратная | — |
| `A9` | Серийный номер | — |
| `90` / `91` | Суммарное число импульсов / с момента включения | — |

## Ответы

**Измерение (`02`, `04`)** — 4 байта параметров: `статус, дальность_старший, дальность_младший, десятые`.
Дальность, м = `старший × 256 + младший + десятые × 0,1`.

Статус: при старшем полубайте `0` (одна цель) младший полубайт — `0` одна цель, `1` обнаружена ближняя цель, `2` дальняя цель, `4` вне диапазона. При ненулевом старшем полубайте (режим нескольких целей) он содержит номер цели, младший — тип: `0` одна, `1` ближняя, `2` дальняя, `3` ближняя и дальняя, `4` вне диапазона.

**Самодиагностика (`01`)** — 4 байта `s3 s2 s1 s0`: `s2` — интенсивность эха; `s1` биты: 0 FPGA, 1 выход излучения, 2 детектор основного импульса, 3 детектор эха, 4 ключ смещения, 5 выход смещения, 6 температура, 7 излучение отключено; `s0` бит 0 — питание 5,6 В.

Характеристики модуля: дальность ≥ 3500 м (автомобиль), ≥ 4200 м (здание), ≥ 2000 м (человек), ≥ 1000 м (БПЛА); минимум 15 м; точность ±1 м; частота 1–10 Гц; питание 4,5–16 В.
