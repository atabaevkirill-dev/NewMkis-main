# TL.0009: сервисное управление

Новый клиент управляет поворотным устройством только ASCII-командами сервисного протокола вида `$...#`.

| Назначение | PAN | TILT |
|---|---|---|
| Состояние оси | `$m#` | `$M#` |
| Самодиагностика | `$m,1#` | `$M,1#` |
| Ошибки | `$n#` | `$N#` |
| Позиция | `$o#` | `$O#` |
| Скорость | `$p#` | `$P#` |
| Занятость | `$q#` | `$Q#` |
| Стоп | `$u#` | `$U#` |
| Скорость движения | `$w,targetSpeed#` | `$W,targetSpeed#` |
| Абсолютная позиция | `$x,targetPos,maxSpeed#` | `$X,targetPos,maxSpeed#` |

Ограничения Rust-драйвера:

- скорость PAN: `0 < speed <= 50 °/с`;
- скорость TILT: `0 < speed <= 19 °/с`;
- диапазон профиля PAN: от `-360°` до `360°`;
- диапазон профиля TILT: от `-90°` до `90°`;
- от 1 до 1000 циклов;
- пауза от 0 до 300 секунд;
- при отмене профиля обе оси получают команды стоп.

Порт управления задаётся в конфигурации. Рабочее значение проекта — `9762`.
