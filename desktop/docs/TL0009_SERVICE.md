# TL.0009: сервисное управление

Новый клиент управляет поворотным устройством только ASCII-командами сервисного протокола вида `$...#`.

| Назначение | PAN | TILT |
|---|---|---|
| Состояние оси | `$m#` | `$M#` |
| Самодиагностика | `$m,1#` | `$M,1#` |
| Ошибки | `$n#` | `$N#` |
| Позиция | `$o#` | `$O#` |
| Скорость | `$p#` | `$P#` |
| Занятость | `$q#` | `$Q#` |
| Стоп | `$u#` | `$U#` |
| Скорость движения | `$w,targetSpeed#` | `$W,targetSpeed#` |
| Абсолютная позиция | `$x,targetPos,maxSpeed#` | `$X,targetPos,maxSpeed#` |

Ограничения Rust-драйвера:

- скорость PAN: `0 < speed <= 50 °/с`;
- скорость TILT: `0 < speed <= 19 °/с`;
- диапазон профиля PAN: от `-180°` до `180°`;
- диапазон профиля TILT: от `-45°` до `90°` (предел, который допускает команда `$8`);
- углы профиля знаковые, в устройство уходят в диапазоне протокола `0.00…359.99°` (`-45°` → `315.00`);
- от 1 до 1000 циклов, пауза от 0 до 300 секунд;
- команда пропускается, только если она обрамлена `$…#` и содержит буквы, цифры, `,` `.` `-`.

Связь и безопасность движения:

- одно постоянное TCP-соединение на устройство, все команды идут строго по очереди; оборванное соединение переоткрывается и команда повторяется один раз (все команды идемпотентны);
- ответ ждётся до 300 мс; отсутствие ответа на команду установки не считается ошибкой;
- ручное движение идёт, только пока кнопка удерживается: интерфейс подтверждает удержание каждые 250 мс, без подтверждения дольше 900 мс драйвер сам отправляет `$u#` и `$U#`;
- любая команда стоп (кнопка «СТОП», Esc, отпускание D-pad) отменяет профиль качки и удержание; команды движения, выданные до стопа, отбрасываются по номеру последовательности;
- ручное движение и самодиагностика отменяют запущенный профиль; при завершении или ошибке профиля обе оси получают стоп.

Направления осей, знак скорости и работа отрицательных углов должны быть проверены на реальной поворотке.

Порт управления задаётся в конфигурации. Рабочее значение проекта — `9760`: проверено на устройстве, на 9761 и 9762 сервисные команды остаются без ответа.
