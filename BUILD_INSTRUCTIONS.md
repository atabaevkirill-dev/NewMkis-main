# Инструкции по сборке автономного исполняемого файла

## Подготовка к сборке

Перед сборкой убедитесь, что все зависимости установлены:

```bash
python install -r requirements.py
```

или

```bash
pip install -r requirements.txt
```

## Сборка исполняемого файла

### Способ 1: Использование подготовленного скрипта

```bash
python build_exe.py
```

### Способ 2: Непосредственно с помощью PyInstaller

```bash
pyinstaller oncam_app.spec
```

или

```bash
pyinstaller --onefile --windowed --icon=icon.ico run_app.py
```

(если у вас есть иконка `icon.ico`)

### Способ 3: Сборка с отладочной консолью (для выявления проблем)

```bash
python build_exe.py --debug
```

## Параметры спецификации

Файл `oncam_app.spec` содержит настройки для упаковки приложения:

- `console=False` - создает GUI-приложение без консоли
- Включает все необходимые библиотеки и ресурсы
- Добавляет папку `translations` для поддержки многоязычности
- Включает все необходимые Python-модули и библиотеки OpenCV

## Результаты сборки

После успешной сборки:

- Исполняемый файл будет создан в папке `dist/`
- Имя файла: `oncam_app.exe`
- Все зависимости будут включены в исполняемый файл
- Приложение может быть запущено на любой Windows-системе без установленного Python

## Устранение неполадок

Если сборка завершается ошибками:

1. Проверьте, установлены ли все зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Убедитесь, что PyInstaller установлен:
   ```bash
   pip install pyinstaller
   ```

3. Если возникают проблемы с OpenCV, попробуйте:
   ```bash
   pip install opencv-python-headless
   ```

4. В случае ошибок с PyQt6, установите:
   ```bash
   pip install pyqt6
   ```

### Проблемы с функцией зума

Если функция зума не работает в готовом приложении:

1. Используйте отладочную сборку для выявления проблем:
   ```bash
   python build_exe.py --debug
   ```

2. Убедитесь, что все зависимости ONVIF установлены:
   ```bash
   pip install onvif_zeep
   ```

3. Проверьте, что все библиотеки OpenCV включены в сборку:
   - В файле `oncam_app.spec` должны быть указаны все библиотеки из папки cv2
   - В скрипте сборки должны быть указаны все необходимые зависимости

4. Запустите отладочную версию приложения и проверьте логи на наличие ошибок, связанных с ONVIF или зумом

5. Если проблема сохраняется, можно попробовать собрать приложение с консольным окном (для диагностики), используя:
   ```bash
   python build_exe.py --debug
   ```
   Это позволит увидеть возможные ошибки при запуске и работе функций зума.
